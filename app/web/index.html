使用须知 / 风险提示

1. 迁移前请关闭相关程序。被占用的文件无法移动，脚本会跳过并给出提示。
2. 目录联接是 NTFS 特性，目标磁盘必须是 NTFS 分区；若不用联接，务必确认已同步注册表。
3. 受保护目录（Windows、WinSxS、WindowsApps、Program Files 根目录等）禁止迁移。
4. 迁移只是把数据换到其他分区，如果目标磁盘是可移动磁盘，拔掉后将无法访问。
5. 建议先在虚拟机或不重要的数据上验证流程，再进行大规模迁移。

关于 CClear

1. 本地优先：界面由本机 WebView2 渲染，扫描与迁移全部在本机执行，不向网络发送任何数据。
2. 迁移可回滚：每次迁移都会写入「迁移记录」，并在动手前导出受影响的注册表项，出问题可一键还原。
3. 开源：项目托管在 github.com/soultt/CClear， 以 MIT 许可证发布，欢迎提交问题与建议。
4. 免责声明：清理与迁移会真实修改磁盘与注册表，请先阅读「设置 → 使用须知 / 风险提示」，重要数据务必提前备份。
